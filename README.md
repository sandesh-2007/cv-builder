# Modern CV Builder

A modern and responsive CV Builder website that helps users create professional resumes quickly.

## Features
- Multi-section resume form (personal details, summary, experience, education, skills)
- Live preview that updates while typing
- Download resume preview as PDF
- Dark/light mode toggle with theme persistence
- Fully built with HTML, CSS, and vanilla JavaScript

## Run locally
```bash
python3 -m http.server 4173
```
Then open `http://localhost:4173` in your browser.
